แนวคิดในการทำงานของผมคือ: **"งานไหนที่ต้องทำซ้ำๆ เราควรให้สคริปต์ทำงานแทน"** เป้าหมายของโปรเจกต์เหล่านี้คือการช่วยลดเวลาการทำงาน (ลด Human Error) และคอยเฝ้าระวังให้ระบบเซิร์ฟเวอร์ทำงานได้อย่างเสถียรตลอด 24 ชั่วโมงครับ

## ✨ โปรเจกต์และสคริปต์ที่พร้อมใช้งาน

*   🚨 **`disk_alert.py`**: หมดปัญหาเซิร์ฟเวอร์ล่มเพราะฮาร์ดดิสก์เต็ม! สคริปต์นี้จะคอยตรวจสอบพื้นที่ว่างของ Linux อัตโนมัติ และแจ้งเตือนสถานะ [CRITICAL] ทันทีเมื่อพื้นที่ใกล้เต็ม
*   💬 **`webhook_alert.py`**: ระบบส่งข้อมูลแจ้งเตือนอัตโนมัติ (API & Webhook) ออกแบบมาให้เชื่อมต่อกับแอปพลิเคชันแชทที่ทีมคุณใช้อยู่แล้ว เช่น Slack, Discord หรือระบบ ChatOps ในบริษัท เพื่อให้ไม่พลาดทุกการแจ้งเตือนที่สำคัญ
*   *(และจะมีโปรเจกต์แก้ปัญหา IT อื่นๆ อัปเดตตามมาอีกเรื่อยๆ ครับ)*

## 🛠️ เครื่องมือและเทคโนโลยีที่ผมถนัด (Tech Stack)

*   **Language:** Python 3 (เน้นการเขียนโค้ดที่อ่านง่ายและบำรุงรักษาต่อได้)
*   **OS Environment:** เชี่ยวชาญการใช้งานและจัดการเซิร์ฟเวอร์ Linux (Ubuntu)
*   **Core Libraries:** `subprocess` (เชื่อมต่อคำสั่ง OS), `requests` (จัดการ HTTP/API)
*   **Version Control:** Git & GitHub (ทำงานเป็นระบบ ตรวจสอบประวัติโค้ดได้)
